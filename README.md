# Count War 2

**在线体验 / Play online:** https://pipygames.com/games/count-war-2-j8c2

Count War is a fun number-running strategy game. Pick math gates to grow your army and beat the enemy in the final fight!

## 技术栈 · Tech stack

- 引擎 / Engine: **Three.js**
- 其他 / Also: WebGL 渲染；Canvas 2D 图层
- 语言 / Language: English
- 部署 / Hosting: 纯静态，index.html 即入口，直接丢到任意静态空间即可
